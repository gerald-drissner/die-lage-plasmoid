# Die Lage v2.0.19

## v2.0.19 highlights

Die Lage v2.0.19 fixes duplicate GeoSphere Austria warnings. If GeoSphere splits one Austrian warning into several consecutive daily slices, the widget now shows one compact warning card with the latest expiry time instead of repeating the same warning several times.
