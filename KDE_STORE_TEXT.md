# Die Lage v2.1.7

## v2.1.7 highlights

- Weather attribution is no longer placed prominently beside the Weather title. Source details are available from a compact info button, while a quiet footer keeps the provider credit visible.
- Refresh buttons now show a clearly visible animated spinner until the asynchronous update has finished.
- RSS publication-age labels can use a continuous color scale. The duration is configurable (120 minutes by default); newest and older colors can be overridden, while empty color fields follow the Plasma theme.
- Includes all reliability, OpenWeather, bilingual UI and helper/version checks from v2.1.6.

## Files

- KDE Store package: `die-lage-2.1.7.plasmoid`
- Full/helper installer: `die-lage-v2.1.7.zip`
- Stable download alias: `die-lage-latest.zip`

The `.plasmoid` contains the Plasma widget only. The full ZIP additionally installs/updates the local Python helper and systemd user units.
