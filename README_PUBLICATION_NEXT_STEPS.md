# What to do next

1. Upload the prepared source repository to GitHub.
2. Create tag `v1.60.5`.
3. Create a GitHub release and attach the three release artifacts.
4. Create the KDE Store product.
5. Upload `die-lage-1.60.5.plasmoid` as the main KDE Store file.
6. Link clearly to the GitHub release ZIP for the helper installation.
7. After publishing, test installation from KDE Store on a clean user profile.
